Adicionar fotografias

Importante: publique somente imagens autorizadas, respeitando pessoas, comunidades e momentos que não devem ser fotografados.

Use JPG, PNG ou WebP. As imagens são reduzidas antes da publicação para carregar mais rápido. As fotos publicadas ficam visíveis ao público.

Cada imagem cria uma publicação no repositório. Após enviar, clique em “Publicar alterações” para atualizar a galeria.

Gerenciar portfólio

As alterações só aparecem no site depois de publicar. A atualização do GitHub Pages pode levar alguns minutos.
